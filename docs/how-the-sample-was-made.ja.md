# 見本ができるまで —— 6人のなかまのスムージー

[English](how-the-sample-was-made.md)

見本の[「6人のなかまのスムージー」](../README.ja.md#5分で試す)が、どんな順番でできたかを、段階ごとにかかった時間と一緒に記します。
時間はファイルの記録から出しているので、最初にプランを書いたところから始まります。それより前の話し合いは記録に残っていません。

家族の前での上演まで、ここに書いたことはすべて同じ日のことです。

## 1. 種

毎朝スムージーを作っている人が、家族に**自分で**話したい、と言いました。
誰かに頼まれたわけではありません。これで、いちばん大事なことがすぐに決まりました。語り手はその人で、作品のことはすべてその人が決める。
AI は案を出し、確かめ、下書きをしました。選んだのは作った人です。

もう1つ、早いうちに決めたことがあります。**スムージーを飲ませようとする話にはしない。** 試飲は上演のあとに、飲みたい人だけがしました。

## 2. 取材（プランの前。時間は記録に無し）

いくつかの質問に、ひとことずつ答えてもらいました。

| 質問 | 作った人が選んだこと |
|---|---|
| なぜ作り始めたの？ | 体の「サビ」を防ぎたかった。血管をしなやかに保ちたかった |
| 何を、どれだけ入れる？ | 材料は6つ。分量は2人分 |
| どうやって作る？ | ナッツと豆乳を先に。そのあと残りをぜんぶ入れて1分 |
| なぜその材料？ | 松の実はむかしの伝説から。ゴールデンキウイはビタミンCが多いから |
| 主役はどの材料？ | トマトとナッツ |
| 物語の中で何と呼ぶ？ | 「お母さん」 |
| 音楽は？ | 候補から選ぶ |

## 3. プランと最初の確かめ（最初に書いた段階）

物語の骨組みは、材料そのものから出てきました。**材料ひとつずつに得意技があり、サッカーの選手のようにパスを出し合う。**
そのうえで、材料どうしの「パス」の候補を AI が出典つきで5つ調べ、作った人が3つを選びました。

## 4. 台本（プランの5分後）

5枚、声に出して約6分。いちばん年下の聞き手にも分かる言葉で書きました。

## 5. 言いすぎを直す（午前中いっぱい）

作った人が最初に話した言葉は、物語に入れる前に確かめ、いくつかを直しました。

| 最初の言葉 | 語りでの言い方 |
|---|---|
| 血管をきれいにする | 血管がやわらかく広がる力を助ける、という研究があります |
| 抗酸化作用・アンチエイジング | ひとりだけ取り出すより、チームで入っているほうが、強いらしいのです |
| 松の実は仙人の実 | 仙人になった人の、**伝説**があります |

あとから足した2つ（リコピンとオレイン酸という名前、しぼりかすの正体）も、同じように確かめてから入れました。出典は見本の `sources.md` にあります。

## 6. 絵・音・音楽（台本の15分後）

絵は5枚。AI で作り、材料をキャラクターにしました。音は2つ。6人のなかまが1人ずつ出るときの「ぽん」と、ミキサーの音です。
音楽は、候補を AI に出してもらって、その中から好みの曲を選びました。

## 7. エンディング動画（約1時間15分）

まず曲の拍と区切りを測り、絵が1枚も無いうちに、曲に合わせて26の席を決めました。
6人のなかまが1人ずつ登場し、踊り、スムージーに変身する、という流れです。そのあと、席ごとに1枚の絵を作り、それぞれの絵から短い動きのクリップを作って、最後に動画に仕上げました。

## 8. 上演（同じ日）

作った人がひとりで、語りも、スライドを進めるのも、音楽を流すのも、すべてしました。

**記録に残っている作業は約3時間**です（最初のプランから、エンディング動画ができるまで）。

---

## 公開版

公開の前に、作った人から書面で許諾をもらい、見本を次のように作り直しました。

- 音楽を、パブリックドメインの録音に替えました。エンディング動画は、新しい曲に合わせて並べ直しました（曲は途中を省いて使っています）。はじめに1席（空っぽのミキサー）を足しました。
- この家族の名前・年齢・家族向けの演出の行を外しました。子どもへの問いかけの宛名も外しました。
- 語りは変えていません。英語版は、その語りを訳したものです。
- 自分のものに替えられる場所（穴）に印を付け、手引き（`holes.md`）を添えました。
