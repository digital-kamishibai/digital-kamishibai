## [Slide 2] 6人のなかま

> [Picture] pictures/02.jpg

> [Text] left 0.70in top 0.28in width 11.93in height 0.70in size 32pt bold color #3B7A3B
> 6人のなかま

> [Sound] sounds/pon.mp3

> スライドが開くと「ぽん」が6回鳴る。♩ 鳴り終わってから話し始める

> 問いかけ（1本だけ。入れなくてよい）: 「材料は、6つ。6人の、なかまです。」のあと、6人が並んだ絵を見せながら「この6つの中に、何色がある？」と聞く。答えたそうな子に振る。答えが出たら紹介へ進む（答えを正さない）

材料は、6つ。／ 6人の、なかまです。♩

カシューナッツ。／ 三日月の形をした、木の実です。／ 体にいい油と、血をつくる材料になる鉄を、持っています。

松の実。／ 小さな粒の、兄弟です。／ むかしの中国には、松の実を食べて仙人になった人の、伝説があります。／ 体のサビを防ぐ、ビタミンEも持っています。

ミニトマト。／ 小さいけれど、赤い色が自慢です。

ゴールデンキウイ。／ 緑のキウイより、ビタミンCが、ずっと多いんです。

ミックスベリー。／ 色とりどりの、小さな仲間たち。

そして、豆乳。／ 大豆からできた、白い飲み物です。／ みんなをつないで、なめらかにしてくれます。

## [Slide 3] なかよしのパス

> [Picture] pictures/03.jpg

> [Text] left 0.70in top 0.28in width 11.93in height 0.70in size 32pt bold color #3B7A3B
> なかよしのパス

> いちばんの「へえ！」の枚。ゆっくり

この6人は、ひとりずつでも、体にいい。／ でも、いっしょに入ると、おたがいを助けます。／ サッカーの、パスみたいに。♩

まず、トマトの赤い色。／ この赤の正体は、リコピンという名前の色です。／ リコピンには、体のサビを防ぐ力がある、と考えられています。♩

でも、リコピンは、水にはとけにくくて、油にとける。／ だから、トマトだけだと、体に入りにくい。♩

そこへ、ナッツが、パスを出します。／ ナッツの、油です。／ カシューナッツの油には、／ オリーブオイルと同じ、オレイン酸という油が／ たくさん入っています。

リコピンは、油と仲よし。／ ナッツの油といっしょだと、体に、ぐんと入りやすくなります。♩

もうひとつのパスは、キウイから。／ 木の実や豆の鉄は、体に入るのが苦手ですが、／ そこへキウイのビタミンCが、手を貸します。

キウイは、松の実にもパスを出します。／ 松の実のビタミンEが体を守ってくたびれたら、／ キウイのビタミンCが元気を戻してあげる——と考えられています。♩

ナッツからトマトへ。／ キウイから、木の実と豆へ。／ キウイから、松の実へ。／ ひとりで走るより、パスをつないだほうが、ゴールに近づく。

## [Slide 4] チームで体を守る

> [Picture] pictures/04.jpg

> [Text] left 0.70in top 0.28in width 11.93in height 0.70in size 32pt bold color #3B7A3B
> チームで体を守る

トマトとナッツには、／ 血管がやわらかく広がる力を助ける、という研究があります。／ ゴムホースがしなやかなら、水は、すいすい流れますね。♩

それから、体のサビを防ぐものは、／ ひとりだけ取り出すより、／ いろいろな色の食べ物の中にチームで入っているほうが、強いらしいのです。♩

走ったり、出かけたり、みんなと遊んだり。／ そうやって元気に動ける時間を、健康寿命といいます。／ お母さんは、その時間を長くしたい。♩

このスムージーには、体を守る材料が、いろいろ入っています。

## [Slide 5] 作り方

> [Picture] pictures/05.jpg

> [Text] left 0.70in top 0.28in width 11.93in height 0.70in size 32pt bold color #3B7A3B
> 作り方（2人分）

> [Text] left 8.40in top 2.00in width 4.30in height 4.70in size 21pt align left anchor top color #4A362A
> カシューナッツ　6〜7粒
> 松の実　10粒
> ミニトマト　4個
> ゴールデンキウイ　1個
> ミックスベリー　1/2カップ
> 無調整豆乳　100ml
>
>
>
> 1. ナッツと豆乳を先にまぜる
> 2. 残りをぜんぶ入れて1分

> [Sound] sounds/mixer.mp3

> [Video] videos/ending.mp4

> スライドが開くとミキサーの音が鳴る。♩ 鳴り終わってから話し始める
> 画面に2人分の量が出ている。数字は読まなくてよい

作り方は、かんたんです。／ 2人分の量は、画面に書いておきました。♩

まず、カシューナッツと松の実を、豆乳といっしょにミキサーへ。／ かたい木の実を、先に細かくしておくんです。

つぎに、トマトと、キウイと、ベリーを、ぜんぶ入れて、1分間。

ジュースとちがって、しぼりかすになるところも、まるごと入ります。♩

しぼりかすの正体は、食物繊維。／ おなかの中の細菌たちのごはんになって、／ おなかの調子をととのえます。♩

6人のなかまが、ひとつになりました。♩

これが、お母さんのスムージーです。
