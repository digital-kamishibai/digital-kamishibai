# 穴の手引き —— 6人のなかまのスムージー

この紙芝居は、毎朝スムージーを作っている人が家族に向けて作り、その日のうちに上演したものです。
見せる相手は子どもに限りません——パートナーや友だち、教室のみんな、大人の仲間に向けても、同じように作れます。
公開にあたって、**作る人が自分のものに替えられる場所（穴）** に印を付けました。
穴は空欄ではありません。作った人が埋めたものが、そのまま入っています——それが「埋めた例」です。
語り手の画面では、穴の語りが**薄い黄色の背景**で出ます（台本では、行の頭に `~ ` が付いている所）。

穴だけを替えても、自分の紙芝居になります。物語の骨組み（材料ひとつずつに得意技があり、組み合わせると助け合う）は、
どの料理にもそのまま使えます。

| 穴 | 場所 | 替えられるもの |
|---|---|---|
| 1 | 1枚目（4・5枚目の結びにも） | 語り手と、作り始めた理由 |
| 2 | 2〜5枚目 | 自分のレシピ |
| 3 | 全5枚 | 音楽（BGM） |
| 4 | 5枚目のあと | エンディング動画 |
| 5 | 2枚目 | 問いかけ |
| 6 | 全5枚 | 絵 |

---

## 穴1 語り手と、作り始めた理由（1枚目）

**どこに**: 1枚目の語り全体。「お母さんは、毎朝、スムージーを作っています。」から「今日は、…お話です。」まで。
語り手は、4枚目の終わりと5枚目の最後の行にも出てきます。語り手を替えたら、そこも合わせます。

**何を**: 語り手と、その料理を作り始めた理由。

**なぜ**: いつも食べている人にとって、毎日出てくる料理は「あたりまえ」です。作っている本人が理由を話すと、
その料理は「**誰かが選んで、続けてきたもの**」に変わります。この1枚は、科学の話の前に置く「人の話」です。

**作った人の埋め方**: **いつも作っている本人**が語り、作り始めた理由を自分の言葉で2つ話しました。「体のサビを防ぎたかった」と「血管をしなやかに保ちたかった」です。

**ほかの埋め方の例**:
- 「おばあちゃんの味を、子どもにも残したかったから」
- 「忙しい朝でも、5分で作れるから」
- 「最初は失敗ばかりで、10回目でやっとおいしくなったから」

理由に**健康の話**を入れるなら、言いすぎていないかを確かめておくと安心です（下の「この見本の見どころ」に、この見本で直した例があります）。

## 穴2 自分のレシピ（2〜5枚目）

**どこに**: 2枚目の材料の紹介、3枚目の組み合わせ（パス）、4枚目の体の話、5枚目の作り方・画面の分量。

**何を**: **自分の得意料理**。材料1つずつの「得意技」と、組み合わせると何が起きるか。

**なぜ**: 「ひとりずつでも役に立つけれど、組み合わせると助け合う」という骨組みは、どの料理にもあります。
材料をキャラクターにすると、聞く人は「誰が、誰に、パスを出すのか」を追いかけられます。

**作った人の埋め方**: カシューナッツ・松の実・ミニトマト・ゴールデンキウイ・ミックスベリー・豆乳の6つ。
組み合わせは3つ（トマトの赤い色×ナッツの油、植物の鉄×ビタミンC、ビタミンE×ビタミンC）にしぼりました。

**ほかの埋め方の例**:
- カレーのスパイス（ターメリック×黒こしょう、玉ねぎを炒めると甘くなる）
- おにぎり（ごはん×塩、のりで手がべたつかない）
- 味噌汁の具（だし×味噌、豆腐×わかめ）

**AI と一緒に調べる**: この見本では、材料ごとの得意技と組み合わせを、AI に聞きながら調べました。
AI の答えはそのまま語りにせず、**出典を出してもらい、確かめてから**使いました（下の「この見本の見どころ」）。

**料理を替えると、いっしょに替わるもの**:
- 題: 台本の1行目と、1枚目の `[Text]`。エンディングを焼き直すなら `ending_video.json` の `final_still` と `page` の `title` も
- 5枚目のミキサーの音（`sounds/mixer.mp3`）: 料理に合う音にするか、その行と演出の行を消す
- 4枚目は、体の話でなくてもかまいません（「いっしょに煮ると、味がひとつにまとまる」のような話でも、骨組みは同じです）

## 穴3 音楽（全5枚）

**どこに**: 1枚目の `[BGM]`。1曲が、5枚を通してくり返し流れます。

**何を**: 語りの邪魔をしない曲。

**なぜ**: 曲ひとつで、紙芝居がその家らしくなります。いつも台所で流れている曲や、家族の好きな曲があれば、なおさらです。

**作った人の埋め方**: ある1960年代の映画音楽を使いました。公開版では、だれでも使える録音（シューベルトのピアノソナタ）に替えてあります。
家族の前で流す分には、CD から取り込んだ曲のような手持ちの曲で十分だと考えられています（日本では私的使用の範囲とされています。国によって扱いは違い、これは法律の助言ではありません）。替えたのは、作品を家の外へ配るためです。配信サービスでダウンロードした曲のように、コピー防止を外さないと使えない曲は、家の中でも避けておくと安心です。

**ほかの埋め方の例**:
- 料理をするときにいつもかけている曲
- 家族で出かけた先で流れていた曲
- 子どもがピアノで弾ける曲を、子ども自身の演奏で

この見本では、語りの邪魔にならないように、歌詞のない曲を選びました。歌詞のある曲でも、聞き手がふだん使わない言語の歌なら、語りとぶつかりにくくなります。どの曲を選ぶかは、それぞれの家の好みです。

**自分の曲に替えても、音量はそろいます。** 語る人のプレイヤーが上演の前に曲を測り、大きすぎる曲だけを、語りの下に敷ける大きさにして鳴らします（ファイルは変えません。小さい曲を大きくはしません）。

## 穴4 エンディング動画（5枚目のあと）

**どこに**: 5枚目の `[Video]`。語りが終わってから、語り手が再生します。

**何を**: 材料のキャラクターが1人ずつ登場し、踊り、最後にひとつの料理に変身する、約2分半の動画です。

**なぜ**: 語りで「6人のなかまが、ひとつになりました」と言ったことを、目で見せて終わります。
語りのあとに何も足さず、動画だけで余韻を残します。

**作った人の埋め方**: キャラクターの動きを AI で作り、好きな曲に合わせて並べました。
公開版では、曲をだれでも使える録音（モーツァルト「フィガロの結婚」序曲）に替え、曲に合わせて並べ直しました（曲は途中を省いて使っています）。

**ほかの埋め方の例**:
- 実際に料理を作っているところを、家族がスマホで撮った動画
- 料理の写真を、作った日の順に並べたスライドショー
- 動画は無しにして、5枚目の絵のまま終わる（それでも成り立ちます）

**見本の動画に、自分の写真を差す**: この見本には、エンディング動画の定義 [ending_video.json](ending_video.json) と曲 `sounds/ending.mp3` が入っています。
動画は曲の拍に合わせた27の「席」に分かれていて、席の時刻は動きません。替えたい席にだけ自分の写真や動画を差せば、差さなかった席は見本のまま焼き直せます。
たとえば「6人が登場する席だけ、うちの台所の材料の写真にする」といった作り替えができます。

```
python ladder/ending-video/build_ending_video.py <作品フォルダ> --storyboard                 # 席の一覧（ending/storyboard.html）を作り、替えたい席を選ぶ
python ladder/ending-video/build_ending_video.py <作品フォルダ> --replace 9=photos/kitchen.jpg   # 席9に写真を差す（動画なら photos/cooking.mp4@3 で3秒目から）
python ladder/ending-video/build_ending_video.py <作品フォルダ>                               # videos/my_ending.mp4 を焼く
```

- 道具は Digital Kamishibai のリポジトリの `ladder/ending-video/` にあります（Python・Pillow・ffmpeg が要ります。くわしくはそこの README）。
  絵の道具と同じく、使わなくても紙芝居は作れます。AI と一緒に作っているなら「席9をこの写真にして」と頼むのが近道です
- 差す写真や動画は、作品フォルダの中に置いておくと、フォルダごと動かしても迷いません
- 焼き直した動画は `videos/my_ending.mp4` にできます。見本の `videos/ending.mp4` は、差さなかった席を切り出す台紙なので、消さずに残しておくと安心です。
  上演で流すには、台本5枚目の `[Video]` を `videos/my_ending.mp4` に書き換えます
- 締めの席（27）は、題名の無い絵 `videos/key_26.png` に題名を描いて作ります。題名を替えるなら、`ending_video.json` の `final_still` の `title` を書き換えます。
  締めの絵はスムージーのミキサーなので、料理を替えたなら `--replace 27=<できあがりの写真>` で差せます（題名はその上に描かれます）
- この道具を使わなくても、スマホの写真アプリや無料の動画編集ソフトで、写真を曲に並べたエンディング動画は作れます。見本の曲 `sounds/ending.mp3` も、そのまま使えます（だれでも使える録音です）

家族の前で流す分には、自分たちで撮った動画や手持ちの好きな曲でかまわないと考えられています（日本では私的使用の範囲とされています。国によって扱いは違います）。作品を配るときや、ルームプレイヤーで家族の外の人へ届けるときは、曲を権利の切れたものにし、写っている人に一声かけておくと安心です。

## 穴5 問いかけ（2枚目）

**どこに**: 2枚目の演出の行。「材料は、6つ。6人の、なかまです。」のあと。

**何を**: 聞いている人への問いかけ。この見本では「この6つの中に、何色がある？」と1回だけ聞きました。**入れなくてもかまいません。**

**なぜ**: 聞くだけの紙芝居に、1回だけ「自分が答える番」をつくります。色は、絵を見れば誰でも答えられます。

**作った人の埋め方**: 答えたそうな子に聞きました。答えが出たら、正さずに紹介へ進みました。

**ほかの埋め方の例**:
- 「この中で、食べたことがないのはどれ？」
- 「いちばん力持ちなのは、誰だと思う？」

この見本では、問いかけを1本だけにしました。語りの流れを止めないためです。何本にするかは、それぞれの家で選べます。

## 穴6 絵（全5枚）

**どこに**: `pictures/` の5枚。題や分量の文字は、台本の `[Text]` から後で重なるので、絵には文字が要りません。

**何を**: 1枚ずつの絵。穴2でレシピを替えると、絵に描かれた材料も替わります。

**なぜ**: 実物の材料の写真なら、聞き手は「いつものあれだ」とすぐに分かります。見本の画風で描き直すと、見本に似るだけになりがちです。
同じ画風で描き直すことは、作り替えに欠かせない工程ではありません。

**作った人の埋め方**: 画像を作る AI（Gemini）で、5枚を同じ画風で描きました。そのときのプロンプトは [plan.md](plan.md) にあります。

**ほかの埋め方の例**（手軽な順）:
- 実物の材料や、できた料理をスマホで撮る（横向きで、上の15%ほどを空けておくと、題の文字が載ります）。
  スマホの写真はたいてい 4:3 なので、左右に黒い帯が出ます。5枚目は右側に分量の文字が載るので、右の3分の1ほども空けて撮るか、
  分量の `[Text]` に `fill`（文字の下の色の帯）を足します
- 子どもが描いた絵を、明るいところで撮る
- 画像を作れるチャット AI で描く: plan.md の `[Prompt style]` と `[Prompt N]` をつなげて貼ります。
  **キャラクターを替えるなら2枚目から**描きます（ほかのプロンプトは、2枚目の絵を手本にする前提で書いてあります）。できた2枚目を添えて、残りを頼みます。
  プロンプトを自分の材料に書き換えるときは、plan.md のその `[Prompt N]` をその場で書き換えます（同じ番号を2つ置くと、絵の道具が止まります）
- 見本の絵をそのまま使う（材料が違っても、「組み合わせると助け合う」という骨組みの話はできます）

写真と絵を混ぜてもかまいません。1枚目だけ家族の写真、残りは見本の絵、という作り替えもできます。

**新しい絵を置いたら、台本の `[Picture]` の行を見ます**。台本は `> [Picture] pictures/02.jpg` のように、絵の名前を書いています。
新しい絵を `02.png` や `IMG_1234.jpg` のような別の名前で置いたときは、その枚の `[Picture]` の行を新しい名前に書き換えます
（書き換えないと、見本の絵が出たままです。ビルダーは、同じ番号の絵が2つあると知らせます）。

## この見本の見どころ —— 言いすぎを直した流れ

健康や科学の話をするとき（とくに子どもに）、いちばん起きやすいのは**言いすぎ**です。
この紙芝居では、作った人が最初に話した言葉を、出典で確かめてから直しました。

| 最初の言葉 | 確かめて分かったこと | 語りでの言い方 |
|---|---|---|
| 血管をきれいにする | 「洗い流す」ほどの証拠は無い。血管の広がる力がよくなる、という研究はある | 血管がやわらかく広がる力を助ける、という研究があります |
| 抗酸化作用・アンチエイジング | サプリで1種類だけとっても、長生きにはつながらなかった。いろいろな色の食べ物をとることは、体の守りと関係がある | ひとりだけ取り出すより、チームで入っているほうが、強いらしいのです |
| 松の実は仙人の実 | 長生きの証拠ではなく、むかしの伝説 | 仙人になった人の、伝説があります |
| ビタミンEをCが元気にする | 試験管では確か。体の中での効き方の大きさは、まだ研究中 | 〜と考えられています |

この見本で気をつけたこと:
- 「〜と考えられています」「〜という研究があります」「〜らしいのです」を**外さなかった**
- 「これを飲めば長生き」「病気にならない」とは言わなかった
- ほかの食べ物や飲み物を「だめ」と言わなかった
- 数字（ビタミン○mg など）は語りで言わず、分量の数字は画面に出した

AI と一緒に調べるときは、「この言い方で言いすぎていないか、出典つきで確かめて」と頼むのが近道です。
出典は [sources.md](sources.md) にあります。
