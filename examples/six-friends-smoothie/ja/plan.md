# 絵のプロンプト —— 6人のなかまのスムージー

この見本の絵5枚を作ったときのプロンプトです（[holes.md](holes.md) の穴6「絵」を、AI で埋めた例）。
`[Prompt style]` はどの絵にも共通の画風、`[Prompt N]` は N 枚目の絵です。

画像を作れるチャット AI で描くときは、`[Prompt style]` と `[Prompt N]` をつなげて貼ります。
1枚目・3〜5枚目のプロンプトは「添付画像と同じ6人」と書いてあり、2枚目（6人のなかま）の絵を手本にする前提です。
キャラクターを替えるなら2枚目から描き、できた2枚目を添えて残りを頼むと、そろいやすくなります。
絵のはしご（`ladder/images/gen_images.py`）で描くときも、`--anchor 2` で2枚目を手本にできます。

### [Prompt style]

```text
子供向け紙芝居のスライド。パステルカラーのやさしい水彩画風イラスト。柔らかい線。かわいらしく、親しみやすい。

構図: 16:9の横長の画面いっぱいに描く。画面の上部15%は、白い無地の帯（文字用の余白。何も描かない）。帯の下に絵の本体。左右に余白・縁・枠を作らない。
```

### [Prompt 1] 表紙「6人のなかまのスムージー 〜パスでつながる体の科学〜」

```text
場面: 朝の明るい台所。窓から朝の光が差し込んでいる。木のテーブルの真ん中に、空っぽの透明なミキサー（ブレンダー）が置かれている。そのまわりに、添付画像と同じ6人の材料のキャラクターが、にこにこしてミキサーを見上げて並んでいる——三日月形のカシューナッツ、しずく形の松の実の3兄弟、赤いミニトマト、半分に切ったゴールデンキウイ（黄色い断面）、ミックスベリーの小さな4人組（いちご・ブルーベリー・ラズベリー・ブラックベリー）、白い紙パックの豆乳。どのキャラにも丸い目とにっこりした口がある。人間は描かない。コップやグラスは描かない。

【文字について】画像の中に文字を一切描かないでください。タイトル・ラベル・説明文・数値・パッケージの文字・ロゴ、すべて不要です。文字は後から重ねます。ただし「文字用の余白」と指示した上部の白い帯は、文字も模様も入れずに白い無地のまま空けておいてください。
```
