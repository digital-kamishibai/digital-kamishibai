# Earlier works: what each one said

**Optional.** Open this when a family makes its second work. A single work does not need it.

Why: a new work tends to "pay off" a hint that the earlier work never gave, or to explain an earlier idea again in new
words — because nobody wrote down what the earlier work actually said (`references/pitfalls.md`, *Earlier works*).
This list is that record. Keep it in the family's own folder, next to the works — not in any work.

When:

- **After each show**, add one row for that work (the retro is a good moment). Copy the words **as the script says
  them**; do not summarise them into new words.
- **Before planning a new work**, read the list. To pay off a hint or reuse an idea, **open the earlier script and find
  it first**, then say it again in the words used the first time.

- **What people and things were called**: the same person or thing keeps the same name across works (a grandparent,
  a pet, a nickname for a machine), so the children recognise it.
- **Songs**: a family often comes to hear one artist or one song as "the sound of" a person or a moment. Note it, so a
  later work can use it on purpose — or avoid it on purpose.
- A hint that a later work paid off: mark it as paid, with the work that did it.
