# Plan template

How to use this file: fill it **together with the maker**, in the maker's language (read the headings into that language
on the spot). Keep the plan in the maker's folder for this work. Every section may say "not yet" — except
**Facts to check**, which is done before the script is written.

---

````markdown
## Emotional curve

| Part | Slides | Feeling | Kind | Event |
|---|---|---|---|---|
| Opening | 1–2 | ⟨curious⟩ | hook | ⟨music starts / a sound⟩ |
| | | | peak / dip | |
| | | | climax | |
| End | | | afterglow | ⟨stop; no explanation, no punch line⟩ |

- No stretch longer than about ten minutes without an event (a video, a change of music, a peak, a drop).
  If there is one, rework the peaks and dips rather than adding slides. **Merge before adding.**
- Count the weight: how many deaths or losses, how many songs in a minor key, how many dips in a row.
  If all three are high, the work will feel darker than any single slide suggests.
- Where is the climax? A work that ends in silence and loss leaves that as its peak.

## Pictures

- Where they come from: ⟨family photos / drawings / generated / a mix⟩
- Style: ⟨colours, drawing style⟩
- If a picture is generated: no real person's name in the prompt (describe them instead); no words in the picture

- List what the narration **asserts about each picture** (a number, a shape, a difference) and check those by eye
  (`references/pictures.md`).

### Picture prompts (only for generated pictures)

The markers `[Prompt style]` and `[Prompt N]` and the labels `Asserts:` and `Seen:` are never translated:
the picture ladder reads them. The prompt is the first code block under each marker.

### [Prompt style]

```text
⟨drawing style, colours, light; 16:9, filling the frame from edge to edge;
no letters, numbers or signs anywhere; where the calm band for the words is⟩
```

### [Prompt 1] ⟨Title⟩

- Asserts: ⟨what the narration says about this picture — a number, a shape, a difference; or "nothing"⟩
- Seen: ⟨filled in after looking at the picture⟩

```text
````
