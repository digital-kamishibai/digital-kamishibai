# ポンチ絵の試作（Skill には未組み込み）

叩き台の「無地の板」の代わりに、**こんな感じの絵、という案**を線画で描いて置く試み（2026-10-30）。
人間どうしなら、台本にポンチ絵を添えて意図を渡す——それを Claude がやる形。画像生成 API は使わない。

- 1回目: 家族の作り手の叩き台（17枚）で試した（2026-10-30）。**Skill（`starting-from-a-seed.md` の
  手順4・`draft_boards.py`）へ組み込むか、やめるかは未決**。その作品での使われ方の記録は、作り手本人のリポジトリにある
- いまは**その1作品専用**（17枚の絵がスクリプトに直書き）。組み込むなら、台本から絵の案を Claude が
  書き起こす手順と、共通の部品（棒人間・地球・太陽・矢印・注記・「下書き」の印）に分ける

## 使い方

```bash
python make_ponchi.py <出力フォルダ>    # svg/ に SVG、出力フォルダに 01〜17.png
```

- SVG→PNG は Google Chrome を画面なしで動かす（パスは直書き）。Skill の道具は標準ライブラリだけの
  決まりなので、組み込むときは `build_work.py` の文字焼き込みと同じ Edge/Chrome の呼び方にそろえる
- 置くときは作品の `pictures/NN.png` へ。無地の板は `pictures/_replaced/` へ移す。そのあと
  `build_work.py <作品> --draft`

## 決めたこと（1回目）

- 左上に「ポンチ絵（下書き）— こんな感じの絵、という案です」、生成りの紙・破線の枠——**完成の絵と取り違えない**
- 絵の主役は、台本の `[Text] place top`（y 36〜180）と `place bottom`（y 720〜864）の帯の間に置く。
  上の文字が2〜3行になる枚（表紙・13枚目）は絵ごと下げる
- 線は SVG のフィルタで少し揺らす（手描きに見せる）。字は UD デジタル 教科書体
- 作り手には**提案**として見せる。「こう描いて」に聞こえないように。「要らない」も答えのうち
